# 第三方组件与许可说明

Python和前端组件的版本记录分别见`requirements.lock`、`frontend/package-lock.json`和Windows运行包中的`release-manifest.json`。各依赖的许可文本保存在[`third_party_licenses/`](../third_party_licenses/)；完整Windows运行包还在`.runtime/licenses/`中保留相应许可文件。

`gmssl 3.2.2`与`toggle-selection 1.0.6`的补充许可记录随相关组件的许可文本一起提供。这些记录说明了本次发行核对的版本和来源，不替代组件原有许可证。

AgentGuard项目本身未声明单独的开源许可证。请勿依据某个依赖的许可证推断项目代码的许可范围。再次分发或修改第三方组件前，请核对其对应的许可文件。
